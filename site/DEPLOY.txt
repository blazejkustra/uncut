Deploying uncut.video (Cloudflare Pages)

site/ is a Next.js app built as a static export (output: "export") into site/out, plus one Pages
Function (site/functions/_middleware.ts, the analytics region cookie, D284). Blog posts are Markdown
in site/content/blog/<slug>.md.

1. Build (from the repo root):
     pnpm site:build
   This runs `next build` and writes site/out/_headers from site/_headers: the CSP of each page gets
   the sha256 of each inline script Next emits, so there is no 'unsafe-inline'. site/out/_routes.json
   (from site/public) keeps the function on HTML pages only. Rebuild before every deploy: the hashes
   change with every build.

2. Preview locally, with the function and the headers (from site/):
     cd site && npx wrangler pages dev out --port 8788
   then open http://localhost:8788/ (add ?region=other or ?region=eu to try either case; without
   a country header you count as EU and see the banner). `pnpm site:dev` is the quick dev server,
   without the function or the headers.

3. Log in to Cloudflare once:
     npx wrangler login

4. Deploy, from site/ every time. wrangler takes the function from ./functions in the folder it runs
   in (not from the folder it uploads), so running it from the repo root would ship the pages
   without the middleware:
     cd site && npx wrangler pages deploy out --project-name uncut --branch main
   A preview first: --branch <name> instead of main gives https://<name>.uncut-2tw.pages.dev.
   Check the result: curl -sI https://uncut.video/ shows set-cookie: uncut_region=... (the function)
   and one content-security-policy with sha256 hashes (the headers).

5. The project and the domain (done once already):
     npx wrangler pages project create uncut --production-branch main
   Cloudflare dashboard > Workers & Pages > uncut > Custom domains: uncut.video.
