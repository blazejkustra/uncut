Deploying uncut.video (Cloudflare Pages)

The site is plain static files in this folder; there is no build step.

1. Preview locally:
     cd site && python3 -m http.server 8000
   then open http://localhost:8000/

2. Log in to Cloudflare once:
     npx wrangler login

3. Create the Pages project once (from the repo root):
     npx wrangler pages project create uncut --production-branch main

4. Deploy (from the repo root, every time):
     npx wrangler pages deploy site --project-name uncut --branch main

   The site is then live at https://uncut.pages.dev. _headers in this folder sets the
   security headers; DEPLOY.txt itself is served too, which is harmless.

5. Attach the domain once:
   Cloudflare dashboard > Workers & Pages > uncut > Custom domains > Set up a custom domain,
   enter uncut.video and confirm. If the uncut.video zone is on the same Cloudflare account,
   Cloudflare adds the DNS record itself; otherwise add the CNAME it shows
   (uncut.video -> uncut.pages.dev) at the registrar. Repeat for www.uncut.video if wanted,
   then add a redirect rule from www to the apex.
